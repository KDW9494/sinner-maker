# Sinner Maker (수감자 메이커)

Limbus Company 수감자들의 어린 시절을 맡아 열 살부터 열여덟 살까지 키우는 육성 시뮬레이션 웹 게임입니다.

**플레이: https://kdw9494.github.io/sinner-maker/**

브라우저에서 바로 열리는 HTML 파일 하나(`index.html`)로 되어 있습니다. 진행 상황은 그 브라우저에만 저장됩니다.

비영리 팬메이드입니다. Limbus Company와 등장인물의 권리는 Project Moon에 있습니다. 수감자들의 어린 시절과 거울세계 설정은 이 게임의 창작입니다.
글꼴: 갈무리(SIL OFL).
